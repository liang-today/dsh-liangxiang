# PR #6 — 固定主面板与三行下落短句

本文记录已验收的现行交互契约。创意来源与兼容边界见
[PR #6 审查](PR6_REVIEW.md)。

## 位置与外观

- 主面板的坐标、尺寸和间距不受短句影响；新增、挤出、超时均不驱动面板位移。
- 短句顶端对齐 42px 梁子图标的顶端，使用图标旁、主面板横向范围内的现有空白。
  右侧停靠时向内镜像，不能跑到主面板外侧。
- 最多三行，行距 22px，额外保留 20px 完整退出空间。视口底部或下方面板限制
  空间时减少行数；空间不足时不遮挡图标或主面板。
- 每句随文本宽度收拢，没有共同底框或尾角。浅色暖白、深色抬升灰底，活跃文字
  保持完整不透明和可读对比度。
- 普通“今日梁相”提示在居中可容纳时居中，只有实际越过视口边缘才左/右对齐。
  按压和短句期间隐藏，结束后恢复；不叠加原生 title。

## 动效与手势

新句在 160ms 内从 3px 微小位移轻显；旧句用 300ms 平滑下移一格。
挤出和超时均保留原句，在 420ms 内继续下沉约 19px 并渐隐，完成后再移除。
发射位置在整个连拍中固定，每句最多停留约 2.4 秒；减少动态关闭位移与动画。

| 操作 | 行为 |
|---|---|
| 单击 | 即时按压反馈，200ms 内没有后续轻拍则开合一次 |
| 间隔不超过 200ms 的双击/连拍 | 玩耍与短句，保持面板原本开/关状态 |
| 超出窗口的两次单击 | 各自开合，不沿用额外连拍等待期 |
| Enter / Space | 即时开合并清除待定指针操作，不产生装饰短句 |
| × / Escape | 即时关闭并清除待定开合 |
| 拖动 / 取消 | 清除待定开合，不发玩耍声音 |

短句最多每 140ms 生成一句，队列有界；文本随机且不连续重复。
玩耍不改投票、余额、模式或梁子称呼。

1.2.1-beta.3 按要求恢复 @XChen446 原始提交 `436a194` 的全部 15 句短句，
仅恢复文案，不回退此处的手势、几何、动效或无障碍修正。短句里的“漏香火”等
是装饰玩笑，不代表真实扣香或赠香。

## 验证要求与已有结果

实际安装包的桌面、窄屏和真实深色主题检查覆盖：

- 图标顶端对齐、左右停靠、四角、视口边缘与空间不足时减行。
- 从首拍到最后退出，逐帧测量面板坐标和尺寸；已有专项实测变化均小于 0.1px。
- 挤出及超时退出时 y 增加、透明度连续降低，文字保留在完整退出空间内。
- 单击收起、间隔 260ms 的两次单击、短双击保持开/关、键盘、拖动与取消。
- 减少动态、无业务 POST、浅深主题活跃文字对比度至少 4.5:1。

主要测试位于 `tests/badge-squish.spec.tsx`、`tests/badge-position.spec.ts` 和
`tests/browser/badge-squish.spec.ts`。完整候选的最终门禁结果见
[CURRENT_ARCHITECTURE.md](CURRENT_ARCHITECTURE.md)，不沿用旧候选的测试数字代替本次验收。
