# 交易视图：当前方案与参考边界

当前 `1.3.0-alpha.12` 为未发布候选。潮汐表现层曾参考同项目的 MIT 设计提案 `design/tide-chart/liangzi-tide-chart.html`，保留贡献者版权；表现层不替换服务器账本或价格依据。

## 当前界面

- 案牍四个工具格压紧，香火交易作为更大的独立菜单行，配小型装饰烛线。缩略图没有价格含义，也不请求行情。
- 普通窗口采用紧凑高度；全屏才展开。标题与钱包、中央鲸鱼、窗口控制和图表工具分开；阶段切换、方向／金额／确认／撤回和底部反馈按固定槽布局，切换早午晚盘、持仓或回执不推动窗口跳动。
- 阶段为轻量分段标签，方向与金额紧邻确认动作；只有主要确认按钮强调填色，保留轻微下压与回弹。确认与撤回同栏同款，金额越界自动钳到可用范围，不增加报错行；三盘图标与文字分层居中，常驻盘名、真实封盘时刻和本人的方向／金额，无仓省略“未投入”，状态采用待开放／可投入／争梁位／已定梁／已收盘／已取消；预计返还仍只作播报，不提前入账。
- 默认 K 线，保留潮汐、分列开高低收、数字轴、缩放／平移／全屏。缩放键旁只保留一份纯文字时间范围，只显示实际视窗（例如今日／近11时36分），不响应点击；滚轮连续平滑缩放，＋／−保留24／12／6／3／1小时与30分钟档位；自动粒度仍可到真实一分钟，不单列粒度选择器。
- 时轴覆盖业务日00:00–24:00，开盘前也展示已记录的真实走势。K线与潮汐共用从真实业务时钟起的浅灰未来区，左边界为当前时间线，「待开梁」靠边界内侧左对齐；不以最后一根行情代替当前时刻，也不补造历史缺口。顶部细色带区分投入／锁定时段，避免多块满高背景叠加；早盘／午盘／晚盘保持真实定梁坐标，并明确标注定梁。
- 标题为「梁股 · 香火市场」，删除重复的场次副标题。原鲸鱼插画放入标题／钱包与窗口控制之间，台词完整换行。右侧全屏＋退出采用小方形，动画开关在其正下方，与两键总宽居中对齐，采用无边框样式；开关使用「大肥鱼／大鱼干」。同角色高清原图按需加载，点鱼有明显探头回弹。水上、水下、等候及明确操作有对应对白，整体游动与局部动作保留，头脸采用向量裁切避开整脸蒙版栅格化；局部鱼尾、发梢、光圈呼吸与游动保留，不同操作有独立姿态、泡泡或盖章；连续滚轮只触发一段可读回应。回执确认后的回应只在 Host 返回已接受状态后出现。
- 静态、减少动态、隐藏或关闭时停止装饰循环。待机文字只在动态可见时低频轮换，操作回应短暂展示；每分钟用本盘实际时间与香池播报，忙时避让，点鱼可立即查看。底栏左2/3分梁位／香池两格，右1/3为我的回执／梁股玩法；数字与炷紧邻，称呼及揭晓加粗，点击信息可听大肥鱼播报；不刷屏播报，不参与账务或发送网络数据。
- 回执与玩法常驻底栏并以浮层打开；24:00后统一揭晓。错误提示复用浮层槽，不增加空白行。

- 夯拉图例与价格共用右侧轴列，在量带旁居中；六位梁位并入底栏，取消原独立读数行；每根K线时段的“本段上香”及夯拉明细移到鼠标附近的轻量提示，图内避边、移开即隐藏，键盘精确读数和触摸查询保留。图表拖动不选中标签或邻接文字，其他普通文字仍可复制。真实上下影线加强描边，没有影线的数据不伪造。玩法分三步、时点和算例呈现。深浅主题沿用原生纸面与蓝灰色，颜色继承DSH的明确选择，包含系统浅色／DSH深色的组合；避免亮蓝高光抢占层次。
- 新v3场早盘07–11、午盘12–16、晚盘17–21各可投入四小时，12／17／22点定梁；旧v1/v2场保留数据库时点和原回执版本。

- 顶部“个人可用／冻结香火”上下两行，共用标签、金额和“炷”的网格列，右对齐金额与竖直对齐单位；图表工具栏保持间隔。底部左侧三列依次为梁位、今日三盘香池、当前盘香池，无新增竖线，金额保持同一基线；当前盘旁以浅色月亮和“午夜揭晓”轻提示，完整24:00规则留在说明，当前连接／取消／收盘状态仍准确显示；大肥鱼开关下显示服务器业务日期／时间，不使用浏览器日期补位。
- 展示金额向零截断为最多四位有效数字，采用万／亿／万亿等中文单位；精确title、辅助读数及可编辑整数保留，账本和六位梁位不变。

## 数据边界

schema 14 使用独立官方分钟表，旧五分钟表保留只读。记录按真实粒度传输和缓存；旧后台只能提供五分钟时，自动粒度至少五分钟，不把历史拆成虚构的小柱。

每页最多288根，首次仅按游标取齐当天，常规冷校准沿用五分钟节奏；分钟实时桶复用已有推送。浏览器缓存总量最多2MiB，过量按旧日淘汰，不缓存余额作为权威。全年分钟数据的本机尺寸证据见验证记录，不等于服务器压测。

烛线聚合取真实首开、末收、有效极值与新增票量；缺柱、null、换案不硬接。潮汐曲线仅连接已知锚点，不超出相邻端点，也不参与读数、定线和结算。颜色仅表达已确认夯拉分量，未知体量保持中性。

本机观察 Host 的一分钟采样与出图接口保留，和官方行情分离。服务器不保存动画或截图；原主面板梁子素材、互动、钱包冻结、投票与整数结算保持各自边界。
