# DSH侧栏与梁相面板宽度证据

核对：2026-11-08，实际安装DSH `0.2.1-rc.2`发布构建，并以真实浏览器尺寸交叉检查；不把旧版TS参考仓当成本版本证据。以下均为CSS像素，截图物理像素与浏览器缩放不能直接比较。

| 对象 | 实现与实测 |
| --- | --- |
| DSH展开侧栏 | 默认280px；拖动钳制264–420px，保存的非默认宽度可不同 |
| DSH侧栏内容 | root采用border-box，左右内边距各12px；默认内容区256px |
| DSH折叠 | 小于1024px默认折叠；普通Web rail为56px，特定桌面标题栏模式为0；手动展开恢复正常宽度 |
| 梁相面板 | 固定外框256px、border-box、左右内边距各12px与边框各1px，实际内容230px |
| 默认对齐 | 入口x=12，面板外框x=12–268，中心140；与280px侧栏中心同轴 |

实际发布文件定位：

- `@deepseek-ai/dsh-client-ui-layout/lib/client.js`：`computeColumns`第38行，展开尺寸约束第39行，初始280第396行，拖拽／恢复逻辑第413–420行；折叠判定第237–244行。
- `@deepseek-ai/dsh-client-ui-sidebar/lib/client.js`：root的border-box与`padding:6px 12px`位于第91行；实际宽度传入位于第292行。
- 梁相：`src/client/badge-position.ts`的`PANEL_WIDTH`、`BADGE_MARGIN`、`defaultBadgePosition`；`src/client/Panel.tsx`的面板样式；`src/client/Badge.tsx`的入口绝对位置。

现状有意对齐原生侧栏**内容区**，并非整个侧栏。若日后批准改为280px整栏对齐，必须同时调整默认面板左锚点，避免在x=12上直接加宽后侵入主区、中心偏移。自由拖动、保存位置、边缘钳制及折叠侧栏仍需独立处理，不能把梁相缩成56或0。

主面板加宽与市场窗口宽度是两项独立决策。280px整栏齐边曾做草图和测试，实看后已按最终反馈回退；alpha8保持256px内容宽与默认x=12，保留梁股直达及图标＋牍／祠，以紧凑统计和大数显示释放空间。独立边缘钳制不改写入口坐标；指针关闭失焦、键盘关闭归还实际来源。香火市场普通窗口的800px上限、响应式与全屏由独立市场样式控制。
