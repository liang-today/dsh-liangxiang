# 020 — 梁标 V0.1 正确 UI（Mock 阶段）

实现位于 `src/client/`。数据为 mock 种子（`store.ts`），业务转移全部走 `src/domain` 纯函数;真实 Token 与本地权威服务在下一里程碑接入，UI 接口不变。

## 入口

- 座位：`shell.overlay`（docs/003 行 C1/C2，注册经 `compat/dsh/overlay-slot.ts`，处置随插件 fiber）。
- `BadgeButton`：32px 圆形入口，**图标就是当前梁子五态**（`LiangAvatar size=30 hideLabel`，`aria-hidden`），`title` 恒为 **今日梁位**、`aria-label` 为 `今日梁位：<状态>`，`aria-haspopup="dialog"`、`aria-expanded` 跟随开合。
- **自由放置**：指针拖拽到画面任意位置，逻辑集中在 `badge-position.ts`——加载/窗口 resize 时把坐标夹回可视区；位置存 `localStorage['liangbiao:badge-position:v1']`（纯外观偏好，绝非任何权威）；移动超过 4px 才算拖拽，随后那次 click 被吞掉一次，所以拖完不会误开合面板。
- **面板自动就位**：`panelPlacementFor()` 依据徽章位置决定面板画在左侧还是右侧（左侧放不下就翻到右侧），并在贴近上/下边缘时把垂直锚点从居中改为对齐近边，避免面板出画。
- 打开：点击 / Enter / Space（原生 button 语义）。关闭：Escape（badge 与面板均处理）、点击面板外、关闭按钮。
- 焦点管理：打开后焦点移入面板（`tabIndex=-1` 的 dialog），关闭后归还入口按钮。

## 面板四区（`Panel.tsx`，presentational、无 hooks）

```text
┌───────────────────────────────┐
│           今日梁案            ×│  Region 1（单一活跃梁案，居中）
│    DeepSeek Harness 是夯还是拉   │
│                               │
│  我的香火   ┌────────┐    下一炷 │  Region 2（核心区：环居中，两翼 overlay）
│  5 炷      │ 梁气环+梁子 │   3K    │
│            │ 炷/月分轨   │  当量   │
│            └[梁位 83.021952%]───┘ │
│                               │
│ [ 夯：升梁！ ] [ 拉：降梁！ ]  │  Region 3（仅两按钮，等宽标齐）
│          （反馈/禁用原因行）      │
│  三界香火 12,846  五行香客 2,841  上达天听 │  Region 4（社会化，同一行）
└───────────────────────────────┘
```

- **Region 1** 标题与梁案标题均居中（关闭按钮绝对定位于右上角，不影响居中）。授权模式不再显示「本地演示」徽标：软信任语义改由 dialog 上的 `data-liangbiao-authority="LOCAL_FAKE_DEV"` 与 `aria-live` 摘要中的 `LOCAL_MODE_NOTE` 承载（README/docs 仍如实标注）。
- **Region 2** 中央视觉权重最大：`LiangQiRing`（个人梁气）环绕 `LiangAvatar`（全局梁子），视觉叠加、数据解耦——avatar 只读 `snapshot.liangziState`，ring 只读 `personal`。环、头像、环上香火点是**唯一占文档流宽度的列**，因此永远落在面板水平中线；「我的香火 / 下一炷」绝对定位 overlay，不得参与 flex `space-between`。面板宽 **252px**（原 336 的 3/4），环 126px、头像 68px，少挡 DSH 正文。
- **左右两翼是小字 caption**：左=`remainingIncense`（`N 炷`），右=`tokensToNextIncense`（+ `当量` 小注，Pro 口径）。具象交给环本身：fill = 下一炷进度，炷/月/日分轨点 = 剩余香火。可见数字走 `formatCompactCount`：`0–999` 原样，`1,000+` 一位小数缩写成 `1.5K` / `33.4K` / `46.9K` / `1.2M`（10K 以上不再收成整数 K，否则 `33,xxx` 会冻成 `33K`）。悬停或键盘聚焦「下一炷」弹出模型权重表（Pro ×1 / Flash ×0.5 / 其它 ×1）。精确值仍在数字 `title`、`aria-label` 与屏幕阅读器里。
- **环底部只有一个全局数字**：`梁位 83.021952%`（= 全网夯率，6 位小数）。`拉` 不再占第二个大数字，只出现在 tooltip（`夯 83.021952% / 拉 16.978048%`）与 `aria-live` 摘要里。
  - 为什么：两个互补的整数百分比会让「投了一票但 90% 还是 90%」，一票等于没投；单值 + 小数每票都会动。
  - `LiangQiRing` 只负责几何，底部内容由 `footer` 插槽注入（全局数据不进个人组件）。
- 梁位与中央状态取自与**同一个** `PublicLiangSnapshot`；零票显示 `--` + 待开梁。
- 百分比经 `formatRatioPercents(upVotes, downVotes, decimals)`：与状态同源于原始计数，夯率在任意小数位上都**截断**（非四舍五入），拉率取补数。这样 89.6207%（梁圣）不会被显示成看似跨阈值的 `90%`，且两侧恒和为 100%。
- **Region 3** 两个等宽按钮 `夯：升梁！` / `拉：降梁！`；`remaining = 0` 时同时 disabled，`title` 与状态行给出可访问原因（`香火不足…`）。accepted 后状态行短暂显示 `已上香：夯（剩余 N 炷）`。投票类型仍只有 `up`/`down`，升梁/降梁是按钮附属文案，不是第三选项。
- **Region 4** `三界香火`（accepted 总票数，天/人/地香炉 + 三缕青烟）与 `五行香客`（unique voters，取经五众小标）与 **上达天听**（南天门+祥云+奏折）同一行：左侧两统计均分宽度，右缘是角落控件。标签 10px、数值 13px 加粗、`toLocaleString('zh-CN')` 千分位。图标是 `currentColor` SVG（`SocialStatIcons.tsx` / `HeavenHearIcon.tsx`），不再用 emoji。第一次点击上达天听只弹出确认（`向服务器重新对账香火？` / 确认 / 取消），确认后才丢掉本机膨胀的 Token 观测、保留身份与水位，再读服务器权威香火。Hover / 键盘聚焦立刻浮出说明气泡（不用原生 `title`）。不是第五区，也不是第三投票选项。

## LiangAvatar（具象梁子，非 Gauge）

具象肖像（圆形裁切的六态 sticker）：待开梁（未点燃、闭眼低存在感）→ 梁工（安全帽+工牌+咖啡）→ 梁总（西装领带、假笑拍板）→ 梁神（歪光环+开始飘）→ 梁圣（法袍佛光、仍握键盘）→ 梁祖（胡须+朱红法相+最强梁威）。同一张程序员脸递进夯成祖宗。六态两两视觉不同（测试断言序列化差异），状态下方显示中文标签。artwork 可替换，状态语义不可变。

实现：256px PNG（从 JPEG 贴纸抠掉浅灰棋盘底）经 base64 内联进 `liangzi-art.ts`（面板圆形裁切，徽章 `chrome=none` 透明叠在 DSH 上），源图在 `src/client/artwork/`。上下浮动只打在人物层，环/徽章底不动；频率跟 `liang_qi_fill`（下一炷进度）走，fill=0 停，接近满则加快。内联是为了让 DSH 客户端 bundle 维持单文件加载形态。

标签的 `title` 与图片 `alt` 附带该状态的精确夯率区间（如 `梁圣：80% ≤ 夯率 < 90%`），文案由 `liangziRatioRangeText` 从 `LiangziThresholdPolicy` 推导，绝不硬编码，改阈值即改文案。

## LiangQiRing（个人梁气，一个组件两个变量）

- **fill**（环从空到满）= `tokenRemainder / tokenPerIncense`，SVG stroke-dashoffset 连续过渡;颜色 冷调(<70%) → 暖调(70–90%) → 朱红(≥90%)。
- **intensity**（旺盛程度）= `liangQiIntensity(remaining)`（sqrt 阻尼、≤1）：光晕 + 环上香火标记。标记是分轨进位：内轨 **炷**=个位（0–9），外轨 **月**=十位（0–9），环内 **日**=百位（0–9）。月亮不占星星的格子。≥1000 炷改环顶缩写数字。
- 个人数字 overlay 在环的左右两翼（Region 2），不占文档流宽度；环的 `footer` 插槽留给全局梁位值;仍然没有独立的个人成长行。
- Token 跨 50K：容器检测 earned 增长，环顶短暂显示 `凝香 +1 炷`（role=status）。
- `aria-label`：`梁气：剩余香火 N 炷，距下一炷还差 X 当量`。

## 交互规则（容器 `LiangbiaoBadge`）

投票（mock accepted）依次发生：remaining -1 → 对应全局 up/down +1 → 以新计数重建快照（新 sequence）→ 若比例跨阈值中央梁子换态并播放一次短 pulse。梁子换态的唯一原因是全局比例；个人库存下降只削弱梁气。

## 动效与可达性

- `prefers-reduced-motion`：JS（matchMedia hook）+ CSS（`@media` 内 `animation/transition: none`）双保险;禁用悬浮/pulse/凝香动画与环过渡。
- 无持续闪烁;pulse/凝香均为一次性短动画。
- 主题：全部颜色走 `--dsw-alias-*` 语义 token + 静态回退，暗色自动跟随;focus-visible 有 outline。
- 屏幕阅读器：面板内 `aria-live` 摘要（当前梁子状态、夯拉比例、剩余香火、距下一炷当量）。

## Mock 状态分离

`GlobalLiangState`（aggregate + snapshot）与 `PersonalLiangQiState` 在 store 中独立持有;`liangQiIntensity` 仅为渲染时派生。未创建 PersonalAvatarTier / PersonalGrowthTier / nextTier / incenseToNextTier。
