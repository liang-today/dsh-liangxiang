# 020 — 梁相 V0.1 正确 UI（Mock 阶段）

实现位于 `src/client/`。数据为 mock 种子（`store.ts`），业务转移全部走 `src/domain` 纯函数;真实 Token 与本地权威服务在下一里程碑接入，UI 接口不变。

## 入口

- 座位：`shell.overlay`（docs/003 行 C1/C2，注册经 `compat/dsh/overlay-slot.ts`，处置随插件 fiber）。
- `BadgeButton`：48px 圆形点击区，**图标就是当前梁子五态**（`LiangAvatar size=42 hideLabel`，`aria-hidden`），人物背后是静止的交互底座；只有人物层弹跳。`title` 与自定义提示恒为 **今日梁相**、`aria-label` 为 `今日梁相：<状态>`，`aria-haspopup="dialog"`、`aria-expanded` 跟随开合。自定义提示与展开面板上下错开：面板在上则提示在下，面板在下则提示在上。
- **自由放置**：指针拖拽到画面任意位置，逻辑集中在 `badge-position.ts`——加载/窗口 resize 时把坐标夹回可视区；位置存 `localStorage['liangxiang:badge-position:v2']`（纯外观偏好，绝非任何权威）；移动超过 4px 才算拖拽，随后那次 click 被吞掉一次，所以拖完不会误开合面板。
- **面板自动就位**：`panelPlacementFor()` 依据徽章位置选择上/下堆叠，并在接近右边缘时将面板右缘与入口右缘对齐，避免自由拖动后出画。
- 打开：点击 / Enter / Space（原生 button 语义）。关闭：Escape（badge 与面板均处理）或关闭按钮；面板是持续视图，不做误触式外部点击关闭。
- 焦点管理：打开后焦点移入面板（`tabIndex=-1` 的 dialog），关闭后归还入口按钮。

## 面板四区（`Panel.tsx`，presentational、无 hooks）

```text
┌───────────────────────────────┐
│           今日梁案            ×│  Region 1（单一活跃梁案，居中）
│    DeepSeek Harness 是夯还是拉   │
│  今日凝香   ┌────────┐    下一炷 │  Region 2（核心区：环居中，两翼 overlay）
│  5 炷      │ 香火环+梁子 │   3K    │
│            │ 炷/月分轨   │  当量   │
│            └[梁位 83.021952% → 梁祖]┘ │
│                               │
│ [ 夯 · 升梁 ] [ 拉 · 降梁 ]  │  Region 3（仅两按钮，等宽标齐）
│          （反馈行固定占位）        │
│  三界香火 12,846  五行香客 2,841  梁相案牍 │  Region 4（统计 + 右侧礼仪控制列）
│                                      进入梁祠 │
└───────────────────────────────┘
```

- **Region 1** 标题与梁案标题均居中（关闭按钮绝对定位于右上角，不影响居中）。「今日梁案」是 12px 字距标题，梁案为 14px 主信息、最多两行（超出再省略）；梁案正文位于按钮下方，横向占满面板内容区，不继承标题行给声音/关闭按钮预留的窄边。面板固定 **256px**：等于 DSH 默认 280px 侧栏减去两侧各 12px 内边距，默认停靠时不会盖住对话列。授权模式不再显示「本地演示」徽标：软信任语义改由 dialog 属性与读屏摘要承载。
- **Region 2** 中央视觉权重最大：`LiangQiRing`（对外称个人香火环）环绕 `LiangAvatar`（全局梁子），视觉叠加、数据解耦——avatar 只读 `snapshot.liangziState`，ring 只读 `personal`。环、头像、环上香火点是**唯一占文档流宽度的列**，因此永远落在面板水平中线；「今日凝香 / 下一炷」绝对定位 overlay，不得参与 flex `space-between`。环 126px、头像 **96px** 填满内圈；权威称呼显示在头像外，肖像内允许“牢梁”装饰牌匾及与五态同名的小胸牌。梁位与称呼同一行：`梁位 83.021952% → 梁祖`。梁位挂在环下方（`top: 100%`），不再压住梁子。
- **左右两翼是小字 caption**：左=`earnedIncenseToday`（今日共生成 `N 炷`，第三行显示余量），右=`tokensToNextIncense`（+ `当量` 小注，Pro 口径）。具象交给环本身：fill = 下一炷进度，炷/月/日分轨点 = 剩余香火。下一炷可见数字使用整数 compact（如 `33K`），精确值仍在 `title`、`aria-label` 与读屏摘要。悬停或键盘聚焦「下一炷」弹出权重表（Pro ×1 / Flash ×0.5 / 其它 ×0.5）。
- **环下方是梁位与称呼**：`梁位 83.021952% → 梁祖`（= 全网夯率，6 位小数，箭头指向由此夯率形成的梁子称呼）。`拉` 不再占第二个大数字，只出现在 tooltip（`夯 83.021952% / 拉 16.978048% → 梁祖`）与 `aria-live` 摘要里。
  - 为什么：两个互补的整数百分比会让「投了一票但 90% 还是 90%」，一票等于没投；单值 + 小数每票都会动。
  - `LiangQiRing` 只负责几何，底部内容由 `footer` 插槽注入（全局数据不进个人组件）。
- 梁位与中央状态取自与**同一个** `PublicLiangSnapshot`；零票显示 `--` + 待开梁。
- 百分比经 `formatRatioPercents(upVotes, downVotes, decimals)`：与状态同源于原始计数，夯率在任意小数位上都**截断**（非四舍五入），拉率取补数。这样 89.6207%（梁圣）不会被显示成看似跨阈值的 `90%`，且两侧恒和为 100%。
- **Region 3** 两个等宽按钮 `夯 · 升梁` / `拉 · 降梁`（约 38px 高）。`remaining = 0` 时两者为 `aria-disabled`，仍可点击触发方向不同的“香炉空了”本地声效与一行提示 `香炉空了，先去攒香`，但不调用 store、不发请求：夯先试图上扬再坠落，拉则连续低落；离线时原生 disabled。该提示只停 3 秒，随后回到梁小号，不长驻。单击一炷；长按约 280ms 即倾炉，按钮变成炉火/霹雳并改标 `倾炉 ×N`，松手或满 2 秒自动松开，把当前能投的香一次投完（`prefers-reduced-motion` 去掉抖动，可留亮度）。accepted 后状态行短暂显示 `已上香 · 夯（剩余 N 炷）`，一把梭为 `已上香 · 夯 ×12（剩余 4 炷）`。空闲时同一行显示本机梁号（投香量 + 夯拉比，如 `梁小号：勤香 • 死夯梁`），只写 `localStorage`，随业务日与今日香火一起清零，天庭不记账。这条反馈行固定 22px / 12px，上香不得把面板撑高。投票类型仍只有 `up`/`down`。
- **Region 4** `三界香火`（accepted 总票数，天/人/地香炉 + 三缕青烟）与 `五行香客`（unique voters，取经五众小标）占左侧均分宽度。悬停三界香火时，上半仍是今日/累计三界香火，下半是本机 **此身香火**（今日/累计炷数与夯拉比，以及占梁份额）；不是第五区，也不入天庭账本。右缘为单一礼仪控制列：**梁相案牍**在上、**进入梁祠**在下。梁相案牍展开 2×2 主题工具匣：梁相主页、核对香火、在线模式/离线模式、当前版本；模式按钮始终指向另一模式并二次确认，任何断网与重连都不得代替用户点击。点击当前版本弹出独立版本信息，喇叭不再承担隐藏版本手势。Token 声明、快照、重连与档案刷新均自动完成；核香不是日常同步，而是显示异常时放弃未核对本机观察、重读服务器账本的修复动作，必须二次确认。身份重置不放入轻量工具匣。点击进入梁祠打开只读月历。两项都留在第四区，不是第五区、第三投票选项或运营控制。

## 梁祠月历（`LiangciModal.tsx`）

- 从第四区的 `进入梁祠` 打开插件内居中 modal，不跳转 GitHub Pages；桌面最大宽约 880px、高度不超过 86vh。
- 主体是周一开列、按月份实际使用 4/5/6 行的月历，右侧额外 130px 周梁列；月标题区同时显示月梁。弹窗跨月份保持同一高度；六周月份只压缩头像和格内留白，权威称呼保持单行且不可裁切。窄于 760px 时保留列宽并横向滚动，避免把头像与文字压成不可读。
- 今日格只显示专用的「今 / 今日进行中」，不读取今日实时梁子。历史日显示日梁头像；每行右侧是周梁；标题区是月梁。当前周/月以虚线和「暂」标记，数据只到昨天。
- 点击任意日、周、月后，底部固定详情区展示截断到 6 位小数的梁位、夯/拉原始票数、覆盖日数；日梁还列出同日所有梁案标题。
- 无档案、零票待开梁、未来、今日进行中互不混用；历史请求失败保留 last-known-good 并显示 `档案未更新`。
- dialog 打开后焦点进入浮层，Tab/Shift+Tab 困在其中，Escape 关闭并把焦点交还 `进入梁祠`。颜色只用主题 token，支持暗色、缩放、reduced-motion。

## LiangAvatar（具象梁子，非 Gauge）

具象肖像（圆形裁切的六态 sticker）：待开梁（未点燃、闭眼低存在感）→ 梁工（安全帽+工牌+咖啡）→ 梁总（西装领带、假笑拍板）→ 梁神（歪光环+开始飘）→ 梁圣（法袍佛光、仍握键盘）→ 梁祖（胡须+朱红法相+最强梁威）。同一张程序员脸递进夯成祖宗。六态两两视觉不同（测试断言序列化差异），状态下方显示中文标签。artwork 可替换，状态语义不可变。

实现：256px PNG（从 JPEG 贴纸抠掉浅灰棋盘底）经 base64 内联进 `liangzi-art.ts`（面板圆形裁切，徽章 `chrome=none` 透明叠在 DSH 上），源图在 `src/client/artwork/`。上下浮动只打在人物层，环/徽章底不动；频率跟 `liang_qi_fill`（下一炷进度）走，fill=0 停，接近满则加快。内联是为了让 DSH 客户端 bundle 维持单文件加载形态。

标签的 `title` 与图片 `alt` 附带该状态的精确夯率区间（如 `梁圣：85% ≤ 夯率 < 95%`），文案由 `liangziRatioRangeText` 从 `LiangziThresholdPolicy` 推导，绝不硬编码，改阈值即改文案。

## LiangQiRing（个人香火环，一个组件两个变量）

- **fill**（环从空到满）= `tokenRemainder / tokenPerIncense`，SVG stroke-dashoffset 连续过渡;颜色 冷调(<70%) → 暖调(70–90%) → 朱红(≥90%)。
- **intensity**（旺盛程度）= `liangQiIntensity(remaining)`（sqrt 阻尼、≤1）：静态光晕 + 环上香火标记。标记是分轨进位、**可数的字形**：外轨 **炷**=个位、更外一轨 **月**=十位、环内 **日**=百位。底部留空给梁位；≥1000 炷改环顶缩写数字。强光不再无限脉冲，常驻动效只保留人物弹跳。
- 个人数字 overlay 在环的左右两翼（Region 2），不占文档流宽度；环的 `footer` 插槽留给全局梁位值;仍然没有独立的个人成长行。
- Token 跨过 N 个 50K 边界：容器按 earned 的实际增量，环顶短暂显示 `凝香 +N 炷`（role=status）。
- `aria-label`：`香火环：剩余香火 N 炷，距下一炷还差 X 当量`。

## 交互规则（容器 `LiangxiangBadge`）

投票（mock accepted）依次发生：remaining -1 → 对应全局 up/down +1 → 以新计数重建快照（新 sequence）→ 若比例跨阈值中央梁子换态并播放一次短 pulse。梁子换态的唯一原因是全局比例；个人库存下降只削弱梁气。

## 动效与可达性

- `prefers-reduced-motion`：JS（matchMedia hook）+ CSS（`@media` 内 `animation/transition: none`）双保险;禁用悬浮/pulse/凝香动画与环过渡。
- 无持续闪烁;pulse/凝香均为一次性短动画。
- 主题：全部颜色走 `--dsw-alias-*` 语义 token + 静态回退，暗色自动跟随;focus-visible 有 outline。
- 屏幕阅读器：面板内 `aria-live` 摘要（当前梁子状态、夯拉比例、剩余香火、距下一炷当量）。

## Mock 状态分离

`GlobalLiangState`（aggregate + snapshot）与 `PersonalLiangQiState` 在 store 中独立持有;`liangQiIntensity` 仅为渲染时派生。未创建 PersonalAvatarTier / PersonalGrowthTier / nextTier / incenseToNextTier。
