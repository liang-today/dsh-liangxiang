# 梁股香火市场：信息可读性优化

当前候选为`1.3.0-alpha.10`，尚未正式发布。保持原窗口、图表、三盘操作区和底栏结构，
不改变投入、冻结、定梁或派彩规则。

| 优化点 | 当前结果 |
| --- | --- |
| 盘次 | 按时段统一为早盘／午盘／晚盘，覆盖图中标签、按钮、玩法、气泡、回执和辅助说明；协议仍使用原批次数字 |
| 个人资金 | 顶部明确“个人可用”，冻结金额并列；读数仍来自服务器钱包 |
| 点位明细 | 固定底栏只留夯拉与梁位；鼠标附近显示该根K线时段的“本段上香”及夯拉数量，图内避边、离开隐藏，键盘／触摸仍可查精确值 |
| 我的投入 | 三盘按钮两行常驻：盘名和封盘时刻、本人多空方向／金额与状态；未投入也明确显示 |
| 香池 | 底栏中间显示所选盘总香池，固定数字格左对齐，与“24:00后一起揭晓”合并；切盘更新，不将三个独立奖池混成一池 |
| 状态词 | 待开放／可投入／争梁位／已定梁／已收盘／已取消；没有持仓的旁观者不再收到“本金已退回”的播报 |
| 时间 | 动态开关下方的原空位显示服务器业务日期和时间；无有效服务器帧显示占位，不用浏览器日期冒充业务时间 |
| 大数 | 展示金额最多四位有效数字，采用万／亿／万亿，聚合超大数支持亿亿；向零截断，精确提示与辅助读数保留，编辑输入始终是精确整数 |

盘次按钮的11:00／16:00／21:00是**封盘时刻**，图上12:00／17:00／22:00是**定梁时刻**，
两者分别标明。新场仍为07–11／12–16／17–21三个四小时投入段；旧场保存原时点。
梁位继续使用原始票数结算、六位截断展示；金额缩写不改变账本或投票权。

这些是项目自己的三个玩法时段。[期货交易所日盘／夜盘](https://www.shfe.com.cn/services/calenderandholidays/tradinghours/)
有不同的实际安排；界面按本项目时段命名，便于理解。
