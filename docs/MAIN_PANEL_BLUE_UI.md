# 主面板浅蓝水景

当前候选：`2.0.0-alpha.3`，未公开发布。主面板保持256px和四区结构；梁股行情、钱包、冻结、投票、声明与后台分池协议沿用原有实现。

| 区域 | 固定设计 |
| --- | --- |
| 梁案与六态 | 梁案、称呼与六位截断梁位来自同一快照；小难梁使用已确认的浅蓝画像，其余原图像素保持。梁神、梁圣不修边；梁工、梁总、梁祖只处理浅色外缘 |
| 水景 | 连续浅蓝水面置于梁子身后，权威可用香火0–500炷按平方根映射水深，500及以上满水；游鱼仍须大于100炷；消费改变水位，不改变下一炷进度或称呼 |
| 水草与石头 | 不足100炷时，整株从塘底随水深长高；25炷约半高，100炷完整。只左右轻摇，每侧两颗小石头 |
| 游鱼 | 余香严格大于100炷时偶尔游过；两侧均在鱼头上方吐泡，泡泡前景升大、到实时水面破开。静态、离屏、隐藏、关闭及卸载清理动画与计时器 |
| 香火环 | 下一炷进度仍来自确认的Token余量；剩余香火只显示最高量级图形：个位炷、十位月、百位日，最多九枚；原形保留，以柔和香槟金点缀蓝色水景。大额精确余额留在辅助阅读及个人余香短显中，无常驻顶签 |
| 个人数字 | 默认今日凝香。确认结算后显示到账1.5秒、余香2.6秒，再回今日；密集到账合并，保证今日至少可见2秒。确认上香支出也显示个人余香2.6秒；连投延长可读时间而不反复淡出。流式活动采用水草冒泡＋环底呼吸光，不覆盖今日数字或推进未确认进度；无水／极薄水层不冒泡，浅水泡体缩小，但破泡水纹至少18×3px并居中水面，隐藏／静态清理，其余鱼景生命周期独立 |
| 两键与梁位 | 夯／拉等宽，梁位底签与整排投票键等宽。原长按时序、单次请求、声音和双闪电／倾炉动效保留，配色改冰蓝 |
| 社交与入口 | 统计保留完整名称和精确辅助值；主面板梁股直达原市场，案牍不重复市场入口 |
| 案牍修复 | 四个工具保留；核对及模式确认覆盖既有菜单内部，主菜单固定180px高度，保留后果说明与明确确认 |
| 梁标 | 保留48px交互区、圆角方形轮廓及原拍打／自由拖动／漂浮，恢复更圆润的圆角方形与双层蓝色柔光 |

金额视觉紧凑格式最多两位小数、四位有效数字并向零截断；精确余额、六位梁位、编辑整数和所有账本不变。炷／量共享同一单位样式。梁祠共用蓝色纸面、边线与选中色，六态字色随DSH外观而非系统偏好切换。资源生命周期由Badge管理，Panel与水景视图保持纯展示。

三份新素材共75,046字节，沿用同源Host只读资源模式单独缓存；资源名严格白名单，不把URL参数转为文件路径，不经过社区Backend。
