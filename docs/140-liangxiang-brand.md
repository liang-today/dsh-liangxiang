## 2. 统一故事

梁相不是排行榜，也不是对梁文锋本人态度的测量。它是同一社区节点里围绕“今日梁案”进行的每日玩法：

```text
每日开案
→ 使用 DSH 凝成香火
→ 花一炷选择夯或拉
→ 众人香火汇成梁位
→ 梁子随梁位显相
→ 日落结案
→ 日梁入祠，继续汇成周梁与月梁
```

核心叙述：

> 每天一道梁案。你在 DSH 中的输入与输出凝成香火，一炷可以夯或拉一次。所有香火汇成梁位，决定梁子今天显出梁工、梁总、梁神、梁圣还是梁祖之相。日落之后，当日结果封存入祠，成为日梁，并继续汇成周梁与月梁。

## 3. 界面文案

必须使用：

- 产品：`梁相`
- 入口：`今日梁相`
- 面板：`今日梁案`
- 个人左翼：`今日凝香`
- 个人右翼：`下一炷`
- 按钮：`夯 · 升梁` / `拉 · 降梁`
- 成功反馈：`已上香 · 夯` / `已上香 · 拉`
- 个人环：`香火环`
- 社会统计：`三界香火` / `五行香客`
- 礼仪控制：`上达天听` / `进入梁祠`
- 历史：`梁祠`、`日梁`、`周梁`、`月梁`

`梁气` 只允许作为现有代码类型、字段和兼容概念存在，不再作为对外标题、aria 文案或宣传卖点。三界、五行、天庭是被确认保留的仪式语言，不改写为本案香火、本案香客或核对香火。

## 4. 美术规则

全产品视觉母版是 **现代编年志 × 克制梁祠**：

- 80% DSH 原生桌面界面：字体、层级、圆角、边框、密度、暗色模式。
- 15% 编年与档案结构：日历页、周册、月份牌、封存状态。
- 5% 仪式点缀：香火暖色、小面积朱印、极简屋檐或祥云。

暖金和朱红是标点，不是大面积背景。主面板、欢迎层、提示卡、入口图标与梁祠必须像同一个产品；禁止古风手游化、宫殿化、Dashboard 卡片墙和玻璃拟态。

头像内文字是明确允许的美术彩蛋：

- `WAITING / 待开梁` 肖像内可保留“牢梁”牌匾。
- 五个 Active 肖像可保留与权威状态同名的胸牌或小牌匾。
- 像素内文字不参与数据、状态判断或可访问性命名。
- “牢梁”不是第六状态；`小难梁`、`老梁`仍是禁止的产品概念。

## 5. 宣传层级

主标语：

> **用 DSH 攒香火，一炷夯或拉，共同显出今日梁相。**

品牌短句：

> **众香成势，梁子显相。**

传播标题：

> **今天的梁子，是夯上去，还是拉下来？**

短介绍：

> 梁相是一个 DSH 社区玩法。每天一道梁案，使用 DSH 凝成香火，花一炷选择夯或拉；社区香火汇成梁位，决定今日梁子。每天结案后，结果收入梁祠。

信任边界：

> 社区软信任玩法：安装身份和 Token 用量由本机声明。梁位不代表实名人数、真实民意或任何人的本人立场。

非官方声明：

> 非 DeepSeek 官方产品，与 DeepSeek 及梁文锋本人无官方关联。

## 6. 禁止宣传口径

不得使用或暗示：

- “全网投票”“可信公投”“一人一票”“真实人数”
- “DeepSeek 官方”“官方梁位”“梁文锋本人态度”
- cryptographically verified / secure usage voting（当前实现不具备）
- 把 `installation_id` 写成人数或实名用户
- 把梁位写成民调、选举或事实结论

允许使用：

- 社区玩法、社区梁位、今日梁相
- 同一社区节点、参与安装、香客
- 软信任、本机声明 Token
- 每日开案、结案入祠、日梁/周梁/月梁
