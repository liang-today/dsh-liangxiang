# 梁相 Bugfix Backlog

> 作用：集中记录审视中发现、但未纳入当前完成范围的问题。每次准备修复或发版前先看本页；完成后移动到末尾「已关闭」并附 commit/tag。
>
> 最近审视：2026-08-24，当前版本 `v0.8.17-beta`。

## P0 — 外部阻塞

### BF-001 生产身份与 Token 权威仍不可验证

- 现状：DSH 当前只提供本机可读投影和匿名/安装标识；社区后端不能证明真实用户或真实 Token。
- 风险：无法声称 secure / verified usage voting，也不能可靠反女巫。
- 建议：等待或接入 DSH 官方可验证身份与用量证明；在此之前保持 `DEV_STAGING_ONLY` 与软信任文案。
- 状态：`BLOCKED`（结构性，详见 `docs/075-backend-decision.md`）。

## P1 — 应优先修复

### BF-003 模型权重策略缺少可迁移的持久化版本

- 现状：`INCENSE_WEIGHT_POLICY_VERSION` 尚未写入本地日账；升级到“仅 V4-Pro ×1，其它 ×0.5”后，只能保证新 usage delta 使用新权重。
- 风险：同一业务日升级前已累计/上报的其它模型 Token 不能从聚合数中可靠拆出并追溯重算。
- 建议：日账持久化 `weight_policy_version` 与按模型原始 delta 分桶；策略变更时明确迁移或从下一业务日生效。后端 claim 单调，因此不能用客户端简单减账伪装修复。

### BF-004 短窗口与折叠侧栏下仍可能覆盖对话区

- 现状：面板固定 256px，正好匹配默认 280px 侧栏内容宽；DSH 在窄于 1024px 时会把侧栏折叠成 56px。
- 风险：折叠侧栏或极矮窗口下，面板必然进入对话区；当前垂直摆放还依赖近似高度。
- 建议：增加窄窗模式（仍非用户拉伸）：折叠侧栏时改停靠到框架边缘；高度不足时允许面板内部滚动，并用实测 `getBoundingClientRect()` 选择上/下。

### BF-005 首次引导仍是覆盖式面板

- 现状：v0.3.0 已降低遮挡感并增加半透明层，但首次说明仍覆盖真实控件。
- 风险：初见时用户先读说明，不能立即感受梁子和投票闭环。
- 建议：改为两步锚点引导：入口提示「这里是今日梁相」；展开后只在按钮附近解释「用对话攒香，1 炷 = 1 次打梁」。软信任说明放帮助提示。

### BF-006 缺少自动化视觉回归与 a11y 审计

- 现状：结构/键盘/文案有组件测试，真实 Chromium 仍主要靠手工检查；没有截图 diff 与 axe。
- 风险：小屏、缩放、暗/亮主题、长数字、焦点顺序可能在样式调整后悄然回归。
- 建议：增加 DSH profile E2E：暗/亮主题、100%/200% 缩放、0/9/23/105/1000+ 香火、零票、离线、无香火、拖到四角；接入 axe 或等价审计。

## P2 — 体验与维护性

### BF-007 客户端单文件体积过大

- 现状：六态 PNG 以 base64 内联；v0.4.0（含梁祠与首次连接引导）实测 `lib/client.js` 约 914KB、gzip 约 599KB。
- 建议：验证 DSH 插件静态资源路由后改为可缓存资源；在此之前维持单文件可靠加载。

### BF-008 样式仍集中在大型 TSX 内

- 现状：`Panel.tsx` 同时承载结构、长 CSS 字符串与大量内联样式。
- 风险：视觉迭代容易出现重复 token、难以做状态矩阵和视觉 diff。
- 建议：不引入依赖的前提下拆成 `panel-styles.ts` / 小组件，并把间距、圆角、动效时长统一为设计 token。

### BF-009 悬浮入口位置不跨设备同步

- 现状：位置只存浏览器 `localStorage`，属于刻意的纯外观偏好。
- 建议：暂不进入权威状态；只有 DSH 未来提供可靠 UI preference 存储时再接入。

### BF-012 DSH RC 依赖基线出现漂移警告

- 现状：仓库已统一钉住 `0.1.0-rc.7`（CLI、client 类型包、`dsh-web-app`）。干净安装仍可能因 DSH 自己的 rc 闭包打出 peer warning。
- 风险：预发布无兼容承诺；后续 DSH 升级仍可能让半公开接缝先于测试失效。
- 建议：每次升 RC 后重跑 `compat/dsh`、工具调用、干净安装与在线 smoke，并更新 `docs/COMPATIBILITY.md`。
